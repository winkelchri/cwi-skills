# 02 — Word count

**What to build:** Export `wordCount(title)` from `src/slug.js`. It returns the number of whitespace-separated words in the title; a title of only whitespace has `0`. Example: `wordCount("  Hello   World ")` returns `2`.

**Blocked by:** None — can start immediately.
