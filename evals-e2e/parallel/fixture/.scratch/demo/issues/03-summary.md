# 03 — Summary

**What to build:** Export `summary(title)` from `src/slug.js`. It returns `slugify(title)`, a space, and the word count in parentheses. Example: `summary("Hello World")` returns `"hello-world (2 words)"`; a one-word title reads `(1 word)`.
