# 01 — Slugify

**What to build:** Export `slugify(title)` from `src/slug.js`. It lowercases the title, trims it and replaces each run of whitespace with one `-`, within the spec's length rule. Example: `slugify("  Hello   World ")` returns `"hello-world"`.
