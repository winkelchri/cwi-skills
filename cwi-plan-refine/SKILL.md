allowed-tools: Read, Grep, Glob, Write, Edit
effort: high
---

When refining the plan, follow these steps:

1. Read plan.md thoroughly
2. Search for user comments (look for `<!-- -->`, `TODO:`, `FIXME:`, `?`, or inline questions)
3. Address every comment — update the plan text, then remove or resolve the comment
4. If any user instruction is ambiguous, ask for clarification before changing the plan
5. If you disagree with the user's direction, explain your reasoning and propose an alternative
6. Ensure the plan has a complete, ordered task list with all phases and individual tasks
7. Do NOT implement any code — only update the plan document
