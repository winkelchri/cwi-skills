When creating the plan, always:

- clean up the previous `plan.md` file unless user instructs differently
- read the `research.md` file first deeply to get a understanding of the project structure
- If the user forgets to specify for what to create a plan for, ask the user
- If the user gives onymous instructions, ask him for clarification
- Challenge the users intension, if you disagree

Once the users intension is clear, create a detailed `plan.md` document outlining how to implement the plan. include code snippets
